BRIGATA ENVIRO — WEBSITE STATIS (VERSI REVISI)

PERUBAHAN
- Beranda dan Profil digabung menjadi satu halaman Beranda.
- Sidebar: Beranda, Zine, Song, Galeri.
- Song khusus berisi daftar video dari Google Drive.

CARA MENCOBA TANPA HOSTING
1. Ekstrak ZIP.
2. Klik dua kali index.html untuk membukanya di browser.
   Ini berjalan lokal di perangkatmu; agar publik bisa mengaksesnya via internet, gunakan hosting gratis seperti GitHub Pages.

CARA MENGHUBUNGKAN GOOGLE DRIVE
1. Buka index.html dengan editor teks (misalnya Notepad).
2. Cari bagian const DRIVE_LINKS.
3. Tempel tautan berbagi pada key zine1, zine2, song1, song2, song3, galeri1, galeri2.
   Contoh: song1: "https://drive.google.com/file/d/ID_FILE/view"
4. Ganti teks Video 01, Video 02, Video 03 sesuai nama video.
5. Di Google Drive, atur Share / Bagikan. Untuk konten publik, gunakan akses Anyone with the link dan peran Viewer jika memang sesuai.
6. Simpan file dan refresh browser.

PUBLISH ONLINE GRATIS
- Buat akun GitHub jika belum punya.
- Buat repository baru yang bersifat Public.
- Unggah index.html ke repository.
- Buka Settings > Pages, lalu pilih sumber publikasi sesuai instruksi GitHub Pages.
- Setelah dipublikasikan, GitHub memberikan URL berakhiran github.io.
Panduan resmi: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

CATATAN
- Profil organisasi masih berupa teks contoh; ganti dengan profil resmi.
- Tautan Google Drive belum diisi.
- Jangan taruh dokumen privat atau data sensitif di tautan publik.
